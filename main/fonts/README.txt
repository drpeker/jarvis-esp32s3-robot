font_noto_sans_common_14_1.bin
  Noto Sans, 14 px, 1 bit per pixel, 6845 characters (ASCII, Latin-1, Latin Extended incl.
  Turkish ç ğ ı İ ö ş ü Ç Ö Ş Ü; no Ğ). Pre-rendered LVGL "fmt_txt" font in the CBIN layout:
  the file is the font structures with offsets instead of pointers (font_bitmap.cc).
  Same file the earlier Jarvis firmware used for captions.
  Source: github.com/78/noto-fonts (component licence Apache-2.0), commit d45dbc6, cbin/.
  Noto Sans itself: SIL Open Font License 1.1, Google / Noto project.
